# Ferramentas

Stack definida para o frontend:

| Tecnologia | Uso |
| --- | --- |
| React | Construção da interface em componentes. |
| TypeScript | Tipagem estática da aplicação. |
| Vite | Servidor de desenvolvimento e build de produção. |
| Tailwind CSS | Utilitários de estilo, integrado via plugin do Vite. |
| TanStack Query | Gerenciamento de estado assíncrono e cache de dados. |

As dependências estão declaradas em `package.json`.
